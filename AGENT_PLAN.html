UK Headlines Topic Classifier

Set up and run a before/after fine-tuning project: train a DistilBERT headline classifier on general (AG News) titles, evaluate on held-out UK BBC headlines, fine-tune on UK data, then compare accuracy, macro-F1, and micro-F1 on the same UK test set. Also report a Multinomial Naive Bayes baseline (course-aligned).

Agent role. You are implementing this project under uk_headlines/ on the user’s Mac Studio. Create the environment, download data, train, evaluate, and write results into this folder. Do not modify lecture notebooks (lect2/, lect3/, lect4/, lect5/) unless the user asks. Do not commit secrets (api_key.txt, .env).

1. Goal (one sentence)

Show that a news-headline topic classifier adapted to UK news scores higher on a frozen UK test set after UK fine-tuning than the same model trained only on general AG News headlines.

2. Hardware and runtime assumptions

Machine

  • Mac Studio, Apple M3 Ultra
  • 96 GB unified memory
  • Use PyTorch MPS backend

Time budget

  • Stage 1 (AG DistilBERT): typically < 1–2 hours
  • Stage 2 (UK fine-tune): minutes
  • Naive Bayes: seconds
  • Stay well under 24 hours wall clock

DistilBERT is small; prefer Hugging Face Transformers + PyTorch MPS over MLX-LM (MLX-LM is aimed at generative LLMs, not this classifier).

7. Data preparation pipeline

  1. AG News — load fancyzhx/ag_news; keep title + mapped unified label. Cap Stage-1 training with a stratified subset of about 20k–40k titles (faster, still strong). Keep a small AG val split for Stage-1 early monitoring if useful.
  2. BBC UK — load SetFit/bbc-news; map labels; drop entertainment.
  3. Headline text for BBC — if rows are full articles, build a headline proxy: prefer a real title field if present; otherwise first sentence or first ~12–20 whitespace tokens. Document the rule in README.
  4. UK split — stratified 70% train / 15% val / 15% test, fixed seed (e.g. 42). Freeze the UK test set. Never use it for training, early stopping, or model selection.
  5. Save prepared files under data/ (e.g. ag_train.csv, uk_train.csv, uk_val.csv, uk_test.csv) with columns text,label.

8. Training and evaluation

Stage 1 — basic DistilBERT (“before”)

  • Init from distilbert-base-uncased.
  • Train on AG titles → 4 labels. Max length short (e.g. 64).
  • Save to artifacts/model_ag_headlines/.
  • Evaluate on UK test only → artifacts/metrics_before.json (accuracy, macro-F1, micro-F1, per-class F1).

Stage 2 — UK fine-tune (“after”)

  • Load Stage-1 checkpoint (do not re-init from base).
  • Continue train on UK train; early-stop on UK val (about 1–3 epochs; small data — avoid overfit).
  • Save to artifacts/model_uk_finetuned/.
  • Evaluate on the same UK test → artifacts/metrics_after.json.

UK only — fine-tune from base on UK (no AG)

  • Init from distilbert-base-uncased (do not load Stage 1).
  • Train on UK train; early-stop on UK val (same recipe as Stage 2).
  • Save to artifacts/model_uk_only/.
  • Evaluate on the same UK test → artifacts/metrics_uk_only.json.
  • Isolates UK data alone vs AG → UK continued training.

Naive Bayes baseline

  • Train NB on AG titles; score UK test.
  • Retrain NB on UK train; score same UK test.
  • Save models with joblib under artifacts/.

9. Hard constraints

  • DO use the same UK test set for before and after.
  • DO report both macro-F1 and micro-F1 (macro is sensitive to rare classes; micro / accuracy reflect overall instance-level performance — compare them).
  • DO keep scripts runnable with source .venv/bin/activate then python prepare_data.py etc.
  • DO NOT train on UK test or peek at test labels while tuning hyperparameters beyond val.
  • DO NOT train a large generative LLM from scratch.
  • DO NOT commit api_key.txt or dump huge raw HF caches into git.
  • DO NOT rewrite unrelated lecture practicals.
